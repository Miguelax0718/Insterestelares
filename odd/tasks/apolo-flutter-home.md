# Feature: APOLO as the Flutter home screen, connected to the clinical agent
Objective: port the APOLO interface (`web/apolo/`) to Flutter as the primary screen, rebrand the app to APOLO, and wire every circle/action/chat/voice interaction to the clinical agent (`AgentConversationController`, skills, tools, hands-free, TTS). Branch: `feat/apolo-flutter-home`.
Delivery: ask-on-risk; user authorized pushing in several commits. Runner: `~/development/flutter/bin/flutter test` + `flutter analyze`.

## Specs

- **S1 — Scope (verbatim):** "Mi companera implemento el front en una seccion como Apolo, ahora toda la app se llamara Apolo y la pagina principal sera esa q se agrego, revisala conectala para que funcione con el sistema actual del agente. Despliega subagentes" (user chose option 1: port Apolo to Flutter and connect to the Dart agent).
- **S2 — App rebrand & home screen:** App title/branding becomes `APOLO` (keep `package:astramed` import name so nothing breaks; update `MaterialApp.title`, `web/index.html`, Android/iOS/macOS display labels). `ApoloHomeScreen` becomes the initial/default view in `lib/main.dart`; the 5 legacy module tabs remain reachable via a top-bar button ("Clinical modules" / dashboard toggle) so existing `test/widget_test.dart` and module screens keep working. Remove the web-only `url_launcher` button that opened `apolo/index.html`.
- **S3 — Apolo data & urine-biomarker skill (`lib/features/apolo/domain/**`, `data/**`, `agent/**`):**
  - Port `web/apolo/js/db.js` + `core.js` deterministically to Dart: the 23 biomarker definitions (`BM`: ranges, units, boolean flags, derived `nak`), the 8 health circles/modules (`hidratacion`, `renal`, `osea`, `radiacion`, `inmunidad`, `cardio`, `estres`, `metabolismo`: icon id, key value, subtitle, `why`, related modules, status `ok`/`warn`/`crit` with overrides: `hidratacion` -> `ok` when `water >= waterGoal`; `radiacion` -> `crit` when solar storm active), `renalRisk()`, `resorp()`, `infection()`, `sleepQ()`, `stressQ()`, `sampleSlots()` / `sampleState()` countdown, seeded 40-sample history generator + recommendations + alerts for the 5 crew profiles, mapped 1-to-1 onto the existing crew IDs `AST-01`..`AST-05` (and also addressable by Apolo IDs `ana`/`leo`/`sami`/`mateo`/`yuki`), persisted mutations (water +50..2000 ml, exercise +1..300 min, recommendation done toggle, new urine sample submission, custom crew member addition).
  - Expose an `ApoloUrineSkill` + tools registered in the agent's `SkillRegistry`: `get_apolo_modules` (status + key + biomarkers of the 8 circles for the active astronaut), `get_apolo_biomarker_detail(module_id)`, `log_water_intake(ml)`, `log_exercise_minutes(minutes)`, `submit_urine_sample()`, `complete_recommendation(rec_id)`, `show_apolo_orbs(module_ids)` / `hide_apolo_orb(module_id)`. Tools emit `ShowComponentEvent` / state updates so when the user asks the agent about water/kidneys/bones/etc. or says "I drank 500 ml", the agent updates the circles and opens/glows the right orb. Offline deterministic flow included (matches `web/apolo/js/app.js` `ask()` rules when the gateway is unreachable).
- **S4 — Apolo Flutter UI (`lib/features/apolo/presentation/**`):** faithful port of `web/apolo/index.html`, `styles.css`, `dog.js`, `app.js`:
  - Space Cockpit palette (`#0B0C1E` bg, `#1E2050` surface, `#F0FFF1` honeydew text, `#8367C7` lavender, `#5BE38C` ok / `#FFD23F` warn / `#FF5A5F` crit — always icon + word, never color alone) + optional **cockpit high-contrast mode** (pure black/white) and respect `MediaQuery.disableAnimations`. Twinkling starfield + periodic comet (`CustomPainter`).
  - **Apolo astronaut dog** (`CustomPainter` or custom widget porting `dogSVG()` from `dog.js`): helmet, floating bob, periodic blink, pupil look-tracking on pointer move, ear perk when listening, mouth animation while TTS is speaking (`TtsSpeakingSignal`), mood expression (`ok` happy / `warn` flat / `crit` O-mouth + sweat drop) driven by worst module status, wiggle + tip on tap.
  - **Speech bubble** above Apolo with typewriter text, quick-action chips, and last-heard transcript pill. Connected to `agentOrchestratorProvider`: user text/voice goes to `sendUserMessage(text, speakReply: voiceEnabled)`, assistant reply streams/types into the bubble, tool calls show/glow orbs or open detail sheets.
  - **Floating orbs (circles):** on load, show only non-`ok` modules (up to 4); "Show all" / "Urgent only" chips; 3-column stage on wide screens (orbs · Apolo · orbs, 2-column zigzag when >4 on `>=1000 px`), stacked on mobile (`<640 px`, max 6 orbs); size `L`/`M`/`S` by severity with pulsing halo on alerts.
  - **Detail card / bottom sheet** on orb tap: key metric + status chip, water/exercise quick-log box (`+250 ml`/`+500 ml`/custom, `+15 min`/`+30 min`/custom), recommendation checklist, biomarker range bars (personal `lo..hi` band + value dot), 14-sample sparkline, collapsible "Why it matters in space", "Ask Apolo" button (sends a module query to the agent), "Hide" button when `ok`.
  - **Top bar:** APOLO logo + mission day (`Day 142 · Artemis Gateway`), sample countdown pill (pulses yellow when due; tap asks Apolo / submits sample), crew selector button opening the **crew menu** (crew list with status chips, switch astronaut -> syncs `selectedAstronautIdProvider` and `agentOrchestratorProvider.notifier.switchAstronaut`, add crew form, toggles for auto-tips, cockpit high-contrast mode, and voice replies, plus Hands-Free listening toggle + indicator from `handsFreeControllerProvider`).
  - **Bottom ask bar:** text input + send button + mic button (push-to-talk when hands-free is off; pauses/resumes hands-free cleanly).
- **S5 — Tests:** unit tests for `ApoloBiomarkerEngine` / repository / `ApoloUrineSkill` tools + offline flow; widget tests for `ApoloHomeScreen` (renders dog, initial alert orbs only, "Show all" reveals orbs, tapping an orb opens detail sheet and logs water, crew switcher switches astronaut, typing a message sends to `AgentConversationController`, high-contrast toggle). Existing 241 Flutter tests must stay green.
