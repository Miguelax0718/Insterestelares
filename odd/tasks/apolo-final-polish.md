# Feature: APOLO Chat Orbs, Progressive Mission Simulator & Unified Agent/Sidebar Polish
Objective: Integrate `feat/apolo-chat-orbs` floating chat/component orbs into `main`, upgrade Mission Simulator so all crew start nominal and simulate progressively with event triggers, remove the legacy "Modules" dashboard UI while ensuring all capabilities live in APOLO via agent cards and the Crew Sidebar, working on `main`.
Branch: `main` | Delivery: single-pr (working directly on `main` per user instruction) | Runner: `flutter test --no-pub`

## Specs

- **S1 — Scope (user, verbatim):** "Necesito q revises los ultimos commits de main, se supone q se mergeo feat/apolo-chat-orbs, este deberia reemplazar los cards q trae el agente con las peticiones por esferas de estilo similar al resto de la ui. Ademas lo de feat/simulador-mision, este basicamente debe hacer que todos los tripulantes esten normal al inicio y se simule progresivamente ademas de tener la capacidad de llamar eventos para probar, Ojo esto esta pero con la UI antigua de "modulos" esta seccion ya no debe existir solo debemos sacar lo necesario de ahi para mostrarlo con el agente, en teoria esto ya esta con cards, revisa que este. Toda la funcionalidad la debe poder mostrar el agente, ademas de ser accesible por el sidebar q muestra a los tripulantes. Despliega subagentes, los necesarios con Sol 6.1, este deberia ser el ultimo pulido del proyecto, todo debe funcionar de punta a punta, trabaja en main."
- **S2 — APOLO Chat Orbs (`feat/apolo-chat-orbs` minus legacy `UI-URANO` modules):** Replace the inline `_buildDynamicComponentsTray` card list in `ApoloHomeScreen` with floating `ApoloChatOrbWidget` circles and `ApoloChatSheet` overlay cards (`apolo_chat_orbs.dart`), add `QueryAwareDeterministicFlow` (`agent_contracts.dart`, `agent_conversation_controller.dart`, `apolo_urine_skill.dart`) with `speakReply` voice gating, and support all core, microgravity (`zero_g_horizon`, `dva_gaze`), and new cockpit component IDs while preserving PR #14 features (Red-Alert sky/banner/border, `_ThinkingBubbleIndicator`, `ApoloAssessmentLauncherSheet`).
- **S3 — Progressive Mission Simulator & Nominal Crew Start:** All 5 crew members start `nominal` on app boot and when reset (`MockCrewData.getNominalCrew()`, `ApoloRepository.buildNominalStates()`), while keeping existing unit test factory methods intact. A Riverpod `MissionSimulatorNotifier` (`missionSimulatorProvider`) supports mission types (`orbital`, `lunar`, `transit`, `surface`), progressive day-by-day physiological simulation (updating `crewMembersProvider`, `apoloStateNotifierProvider`, `selectedMissionDayProvider`, and clinical triage), event triggers (`sleepLoss`, `solarParticleEvent`, `exerciseFailure`, `workload`), and full nominal reset. Exposed both as an agent skill (`MissionSimulatorSkill`) and as an interactive Space Cockpit card (`MissionSimulatorCard`).
- **S4 — Legacy Modules Removal & Capability Migration:** Remove the `"Modules"` button (`apolo_modules_button`) and legacy 5-tab `AstraMedDashboard` navigation from `ApoloHomeScreen` / `ApoloHomeShell`. Migrate all remaining legacy module features to Space Cockpit cards & agent tools: `fl_chart` vital trends (`VitalsTrendCockpitCard` for `telemetry_chart`), Tap-to-Count manual vitals (`ManualVitalsTapCard` for `manual_vitals`), and offline 10-procedure catalog + situation triage (`MedicalProceduresCockpitCard` for `medical_procedures`), plus update `clinical_navigation_and_procedures_skill.dart` to open APOLO cards/orbs instead of the removed 5-tab dashboard.
- **S5 — Crew Sidebar & End-to-End Integration:** Wire `CrewSidebarDrawer` directly into `ApoloHomeScreen`'s `Scaffold.drawer` with a top-bar Crew Hub trigger button (showing critical badge), and expose Mission Simulator, Telemetry Config, Manual Vitals / Assessments, Medical Procedures, and Reset Nominal from both the Crew Sidebar and the Agent.
