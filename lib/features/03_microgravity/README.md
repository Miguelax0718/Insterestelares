# 🧑‍🚀 Módulo 3: Microgravedad, Sistema Cardiovascular y Musculoesquelético

## 🎯 Objetivo del Módulo
Monitorear las alteraciones fisiológicas inducidas por la microgravedad prolongada: redistribución cefálica de fluidos (síndrome SANS y congestión facial), pérdida de masa ósea, atrofia muscular y cumplimiento de contramedidas de ejercicio (T2 Treadmill, ARED, CEVIS).

## 📁 Estructura del Módulo
- `models/`: Entidades de salud musculoesquelética y protocolos de ejercicio.
- `providers/`: Seguimiento de rutinas diarias de contramedidas y pérdida de fuerza muscular.
- `widgets/`: Mapa corporal anatómico interactivo indicando zonas de riesgo (columna, fémur, pantorrillas).
- `presentation/`: Pantalla del módulo de microgravedad (`microgravity_view.dart`).

## 👨‍💻 Asignación de Tareas
- Integrante responsable de frontend: Visualización del astronauta/cuerpo humano interactivo con partes seleccionables.
- Integrante de lógica médica: Definición de protocolos de ejercicios y recomendaciones de hidratación y sodio.
